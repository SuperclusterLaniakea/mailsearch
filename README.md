# 邮件检索工具 (Mail Search)

一个基于 Rust + egui 的本地邮件（.eml）全文检索工具，专为大量历史邮件存档设计。
它将指定文件夹（含子文件夹）中的邮件解析后建立本地 SQLite 索引库，之后可在数秒内完成关键词 / 正则检索，点击结果即可在界面内直接查看邮件全文。

主要特点：

- **纯本地运行**：不上传任何数据，索引库与程序在同一目录。
- **增量索引**：首次全量建立索引，之后可增量更新，只解析有变化的文件，速度极快。
- **中文友好**：界面与邮件内容中文显示正常；自动处理 GBK 等历史编码。
- **无后缀文件支持**：可自行选择扩展名过滤策略，没有 `.eml` 后缀的邮件文件也能检索。

## 一、功能总览

| 功能 | 说明 |
|---|---|
| 目录扫描索引 | 递归遍历指定文件夹及全部子文件夹，多线程（rayon）并行解析邮件 |
| 扩展名过滤 | 可指定扩展名列表（如 `eml` 或 `eml,msg`），并可选择是否排除列表外文件 |
| 增量更新 | 按文件修改时间（mtime）判断，未变化的文件直接跳过；自动清理已删除文件的索引 |
| 复用索引库 | 下次启动直接使用上次的 SQLite 索引库，无需重新扫描 |
| 关键词检索 | 多关键词逗号分隔，命中任一即显示；大小写不敏感 |
| 正则检索 | 勾选"正则"后按正则表达式匹配，支持多个正则 |
| 检索范围 | 可选是否包含正文；默认覆盖 文件名/主题/发件人/收件人/日期/附件名 |
| 词频统计 | 检索时自动统计关键词出现总次数（正文+主题+发件人+收件人+文件名） |
| 结果排序 | 时间 新→旧 / 旧→新、词频 高→低 / 低→高、主题 A→Z |
| 邮件全文查看 | 单击结果条目，中央面板显示邮件头部与全文（HTML 自动转纯文本） |
| 双击 Outlook 打开 | 双击条目通过系统 `.eml` 文件关联（通常为 Outlook）打开原始邮件 |
| 右键菜单 | 打开文件位置（资源管理器定位）/ 用 Outlook 打开 / 用系统默认程序打开 |
| 实时进展日志 | 界面底部日志面板，彩色区分 错误(红)/跳过(黄)/完成(绿)，附带进度条 |
| 命令行自检 | `--test-parse <文件>` 快速验证单个邮件文件能否解析 |

## 三、使用说明

### 1. 建立索引

1. **目录**：输入或点击"浏览..."选择邮件所在文件夹（含子文件夹）。
2. **扩展名**：填入要检索的扩展名，多个用逗号分隔（如 `eml` 或 `eml,msg`）。
   - 勾选 **排除列表外文件**：只索引列表内扩展名的文件（推荐，速度快）。
   - 不勾选：列表内的文件优先，**列表外（包括无后缀）的文件也尝试解析**。
   - 留空：所有文件都尝试按邮件解析。
3. **增量(利用上次索引库)**：勾选后只解析新增/修改过的文件，并清理已删除文件的索引。首次建库时该选项无实际影响。
4. 点击 **▶ 开始/更新索引**。

扫描过程中底部日志实时输出进度（如 `进度 1234/50000`），顶部显示进度条；可随时点击 **■ 取消**，已解析的部分仍会写入索引库。

> 提示：目录里若有 `.pst`、`.tar`、`.tgz` 等归档文件，本工具无法直接读取，需要先解包（如 `tar -xf`）或从 Outlook 导出为 .eml 后再索引。

### 2. 检索

1. **关键词** 输入一个或多个关键词，用逗号 `,` 或中文逗号分隔，命中**任一**关键词的邮件即显示。
2. 可勾选：
   - **含正文**：同时搜索邮件正文（默认勾选）。
   - **正则**：关键词按正则表达式匹配（大小写不敏感）。
3. 点击 **🔍 检索**，结果出现在左侧列表。

**正则示例**：

| 正则 | 含义 |
|---|---|
| `空客\|AIRBUS` | 包含"空客"或"AIRBUS"（不区分大小写） |
| `RFQ#\s*\d+` | 匹配 `RFQ# 2000249569` 之类的编号 |
| `\d{4}-\d{2}-\d{2}` | 匹配日期 |
| `发票.*报销` | 同一行中"发票"后跟"报销" |

正则语法无效时，日志会给出具体错误提示。

### 3. 查看结果

- **单击**条目 → 中央面板显示邮件全文（头部 + 正文；HTML 邮件自动转为纯文本显示）。
- **双击**条目 → 用 Outlook（系统默认邮件程序）打开原始 `.eml` 文件。
- **右键**条目 → 菜单：
  - **打开文件位置**：在资源管理器中打开该邮件所在文件夹；
  - **用 Outlook 打开**：同双击；
  - **用系统默认程序打开**：按 Windows 文件关联打开。
- **排序**：结果面板右上角下拉框，切换 时间 新→旧 / 旧→新 / 词频 高→低 / 低→高 / 主题 A→Z。
- 也可以直接把邮件拖给其他程序，或用右键"打开文件位置"后自行复制文件。

### 4. 索引库管理

- 索引库默认保存在**程序同目录**下的 `mail_index.db`（SQLite 格式，附带 `-wal`/`-shm` 临时文件属正常现象）。
- 顶部状态栏显示当前库内邮件总数和库文件路径。
- 想重建全新索引：关闭程序，删除 `mail_index.db*` 后重新扫描即可。
- 备份：直接复制 `mail_index.db` 文件即可。

## 四、命令行自检

不启动界面，快速验证某个文件能否被解析：

```
mail-search.exe --test-parse "D:\邮件\某封邮件.eml"
```

输出示例：

```
主题: 来自postmaster@vip.cn的退信
发件人: postmaster <postmaster@vip.cn>
收件人: zhaohq017@avic.com
日期: 2026-01-28 15:41:04
附件: 回复：空客25项新品终版1.6.eml
正文前200字: 很抱歉您发送的邮件被退回…
```

## 五、从源码构建

环境要求：Rust 1.75+（Windows 推荐 MSVC 工具链）。

```bash
cd mail-search
cargo build --release
```

产物：`target/release/mail-search.exe`（约 9 MB，单文件绿色版，可拷贝到任意位置运行）。

### 主要依赖

| 依赖 | 用途 |
|---|---|
| `eframe` / `egui` | 图形界面 |
| `mail-parser` | MIME/邮件解析 |
| `rusqlite` (bundled) | SQLite 索引库 |
| `rayon` | 多线程并行解析 |
| `regex` | 正则检索 |
| `walkdir` | 递归目录遍历 |
| `rfd` | 原生文件夹选择对话框 |
| `encoding_rs` | GBK 等历史编码转码 |
| `chrono` | 时间处理 |

## 六、常见问题（FAQ）

**Q: 双击打不开邮件？**
系统缺少 `.eml` 文件关联（未安装 Outlook / Windows Mail 等）。可先安装 Outlook，或在右键菜单选"用系统默认程序打开"测试。

**Q: 某些邮件检索不到？**
确认该邮件所在文件夹已在索引范围内；文件扩展名是否被"排除列表外文件"过滤掉了；必要时取消勾选"排除列表外文件"重新更新索引。

**Q: 重新索引后数据会丢吗？**
不会。索引按文件路径唯一键 upsert，重复扫描只是覆盖更新；只有增量模式下才会删除"文件已不存在"的条目。

**Q: 支持哪些邮件格式？**
标准 RFC 822/MIME 格式（`.eml`、`.msg` 中的 RFC822 类型、无后缀的邮件原文）。`.pst` 是 Outlook 私有格式，不支持，需先导出。

**Q: 中文乱码？**
界面：程序启动时自动加载微软雅黑/黑体/宋体，正常情况下不会乱码。
邮件内容：UTF-8 优先，非 UTF-8 文件按 GBK 解码；若个别邮件用了其他罕见编码导致正文异常，欢迎反馈。
